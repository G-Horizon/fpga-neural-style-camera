# 单板张掌→握拳检测设计

## 它实际检测什么

这是在固定背景、固定画面中心、近距离下，对“较大展开轮廓→中心收缩轮廓”的轻量近似。它不运行手势神经网络，不分割五根手指。张开的手掌需要在中央区域覆盖足够多的采样点；握拳需要在基本相同的中心位置收缩，不能只是把手移出画面。纸片或其他物体若产生同样轮廓变化也可能触发。

推荐：摄像头固定，选择较暗、静止的背景，手掌朝向摄像头且比背景亮，避免逆光。画面会旋转180度的现有摄像头参数不变。本检测器的“上/下”指经过现有输入方向修正后的小图坐标。

## 空背景校准及操作

1. 系统复位后先让画面中央没有手。首个完整、有效的256×144输入帧保存为背景。该帧不会触发特效。
2. 保持镜头与背景不动，把张开的手掌放在画面中央，连续保持至少2个有效帧。
3. 在24个有效帧的时间窗内，在原中心位置握拳并连续保持至少2个有效帧。
4. 检测器发出单周期 `effect_trigger`，复用现有约60显示帧的反色特效。检测器60个有效输入帧冷却后才接受新动作。在约30新图/秒下，24帧约0.8秒、60帧约2秒，实际均按有效帧计数。

## 采样与默认阈值

每个256×144输入帧按16×9网格取144个绿色通道样点，位置 `x=16*c+8, y=16*r+8`。G通道只是亮度近似。相对冻结背景的绝对差至少24，且当前G值比背景大，才标为亮前景。

中央ROI：网格列4..11、行2..6，共40点，对应约x64..191、y32..111的区域。中心核：列6..9、行3..5，共12点，约x96..159、y48..95。

- 张掌近似：ROI至少20个前景点，中心核至少8点，且左扩展（列4/5）、右扩展（列10/11）、顶部（行2）、底部（行6）都至少占到1点。
- 握拳近似：ROI有8..18个前景点，中心核至少8点，左/右扩展及顶部均没有前景点。底部可保留腕部。
- 整幅144点中，相对背景变化达到48点或更多，按全局变化/闪烁处理并取消动作，不用作手掌。
- 张掌必须连续2帧；握拳也必须连续2帧。两者之间允许短暂中间形态，但总时间窗仍受限。单独握拳、单帧噪声、普通单侧左右移动不能构成完整序列。
