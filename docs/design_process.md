# 创新点与设计流程

## 整体创新点

1. **模型与硬件配合设计**。即使是快速风格迁移神经网络，也会遇到参数量过大、精度过高带来的极大的运算消耗，所以我们在此模型的基础上蒸馏了一个参数量仅为28,995的极小的小模型，在保留完整生成过程的同时显著减少参数与计算量，为单板落地创造条件。
2. **适配残差网络的混合精度部署**。采用INT8权重、选择性地使用8位、10位无符号整数存储中间产生的数据以及明确的舍入和饱和规则，提前修改参数把独立计算并入卷积，降低独立运算和存储开销。
3. **完整网络共享计算资源**。网络的各层轮流使用同一套128路乘法计算单元，并通过缓存重复利用已经读入的数据，将较大的中间结果存入板载内存。上采样按不同输出位置分组计算，减少重复硬件、无效计算和反复读写，使单块FPGA能够完成整个网络的处理。
4. **低分辨率风格生成与高清显示协同**。先在256×144的小图上完成风格处理，再放大用于1080p画质显示。同时，从同一帧高清原画中提取部分轮廓细节，以1/2强度补充到风格画面中，在控制计算量的同时改善大屏上的边缘表现。
5. **连续视频的可靠接续**。生成新画面前，先为结果留好缓冲空间；一帧数据完整写入后，再交给显示模块使用。同时，用帧号将原画与对应的风格结果配对，让采集、计算和显示顺畅衔接，解决已发现的缓冲衔接不当导致的停帧问题。
6. **将各个功能整合为完整的产品**。由FPGA完成风格处理，ESP32提供Wi-Fi热点和本地网页，并结合按键和几个预先约定的语音指令进行控制。手机或电脑连接设备热点后，即可观看风格画面、切换风格；HDMI屏幕支持原画与风格画面对比，现场无需接入互联网。

## 设计流程

1. 设计从需求和资源预算开始：先确定输入、显示、风格和交互要求，核对Ti60的逻辑、DSP、片上RAM、DDR与接口能力，再确定能够实际部署的网络结构。

2. 算法阶段先训练同标准的风格的快速风格迁移网络模型，再训练更为轻量的适配本赛题开发板的轻量模型；把固定的变换转换到卷积运算中、完成校准和量化，建立逐层整数参考。硬件阶段实现卷积、激活、残差和上采样算子，组织共享阵列、行缓存、DDR访问和参数切换。

3. 集成阶段先验证相机直通与色彩、焦距校准，再依次接入CNN、高清细节、HDMI布局和FPS；随后加入按键、esp32-S3网页、麦克风与运动触发，并完成板卡、支柱、亚克力及线束的结构设计。

4. 验证贯穿以上步骤：数值参考检查实现正确，综合与时序检查实现可行，根据上板验证的结果持续更新进度。出现异常时依据内部状态定位至采集、计算、存储、显示或无线环节，再返回相应层修正。最后固定工程和固件，分别写入FPGA及S3 Flash，验证启动，形成测试数据和最终报告。
