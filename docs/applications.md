# 原型的应用方向

本项目首先是一台现场离线互动艺术相机：摄像头拍摄参与者或场景，本地完成三风格变换，直接通过HDMI显示。以下为适用方向，不是已经交付的商业产品或客户案例。

| 方向 | 本原型可提供 |
|---|---|
| 美术馆、文旅、校园互动展示 | 无需互联网的实时艺术形象、原画对比、风格切换 |
| 美育与人工智能教学 | 同输入看内容与风格差异，结合模型/量化/硬件演示 |
| 品牌活动与创作体验 | 独立HDMI视频源、本地手机观看 |
| 小型演出或直播效果预览 | 减少现场电脑的神经计算负担 |

HDMI输出可接普通显示器或兼容的大屏系统。车载、医疗、安防等可靠性要求更高的场景仅可作为远期概念。
