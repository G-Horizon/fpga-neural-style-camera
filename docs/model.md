# 模型、蒸馏与硬件部署

这里使用的轻量的网络是一个带瓶颈残差块的轻量生成器：由于是第四代、较高精度版本，所以训练时将其命名为`d64`。

```text
256×144×3
  → 3×3 卷积：3→8
  → 下采样卷积：8→16，128×72
  → 下采样卷积：16→32，64×36
  → 瓶颈残差块 ×5：32→16→16→32，保留输入相加
  → 转置卷积：32→16，128×72
  → 转置卷积：16→8，256×144
  → 3×3 卷积：8→3
256×144×3 风格图
```

| 项目 | 数值或实现 |
|---|---|
| 卷积／转置卷积层数 | 21 |
| 残差块 | 5 个 |
| 部署参数 | 28,995 个 |
| 256×144 每帧名义卷积计算量 | 96,731,136 MAC |
| 主干通道 | 32；瓶颈内部为 16 |
| 权重 | INT8 |
| 中间激活 | 一般层 U8，残差主干采用带零点的 U10 |
| 单板计算组织 | 共享 128 路乘法计算资源，按层复用 |

**128 路计算资源不等于 128 通道网络；D64 是模型名称，不代表主干有 64 个通道。**

算法阶段先训练同标准的风格的快速风格迁移网络模型，再训练更为轻量的适配本赛题开发板的轻量模型；把固定的变换转换到卷积运算中、完成校准和量化，建立逐层整数参考。硬件阶段实现卷积、激活、残差和上采样算子，组织共享阵列、行缓存、DDR访问和参数切换。

### 高清细节补充的含义

显示端将 256×144 风格图放大至 1920×1080，并从同一帧原画中提取有限的水平方向高频细节，经限幅后以 **1/2 强度**补入风格图。（这里的 1/2 是细节支路的强度，不是把原图和风格图各混合一半）

各正式 FPGA 工程的 `profiles` 已随目录保留配套部署参数；具体结构、训练配置、量化格式见[模型目录](../models/)和[训练代码](../training/)。
