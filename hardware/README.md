# 轻量硬件与机械资料

本目录仅包含自研亚克力平面图、参数、参考BOM、接线入口和一张自有产品实拍。

| 入口 | 内容与状态 |
|---|---|
| [单板R2亚克力](acrylic/single_r2/) | 5种2.7mm DXF、参数和自研生成/检查脚本 |
| [双板D2亚克力](acrylic/dual_d2/) | 底板、两片同型载板和可选顶层/相机/压条的5种DXF |
| [版本与加工说明](mechanical_notes.md) | 历史平面图与当前D4 30mm完整装配的区别 |
| [单板框架参考BOM](bom/single_r2_frame_reference.csv) | R2框架用量与部分更新 |
| [双板D4机械参考BOM](bom/dual_d4_30mm_mechanical_reference.csv) | 当前完整模型数量 |
| [当前装配参数](current_assembly_parameters.json) | 黑PCB、透明亚克力、25×10×2mm长脚垫、D4板间30mm支撑 |
| [单板产品实拍](photos/single_board_product.jpg) | 实装照片 |
| [电气接线](../docs/wiring.md) | 当前单板与以太网双板主链 |
| [SolidWorks完整装配体](/assembly_model) | 单板、双板方案成品的SolidWorks模型 |

DXF为毫米单位、1:1、2.7mm设计板厚；包括轮廓、孔和开槽，不含沉头加工或亚克力攻牙。加工前先按实物孔位、板厚、插舌、切缝、线缆与元件高度复核。
